# Official Axie 3D mixer asset extraction

Source: https://github.com/axieinfinity/unity-axie-mixer3d at commit 63ec82afc7deeec242734e70fea4bb9fffa904cc (2026-08-20). All 6654 downloaded BuiltAssets/Bodies, BuiltAssets/Parts and Data files verified against the repository Git blob SHA-1s. No meshes or textures were generated or approximated.

The source stores Unity YAML .mesh (uncompressed vertex/index hex streams), .prefab (transform hierarchy, ordered skeleton bone references and renderer/material references), .mat, PNG textures and .anim (local transform curves). There are no FBX, GLB or glTF source models in this repository snapshot.

Conversion preserves float32 geometry, indexed triangles, vertex attributes, source transforms and bone order, original inverse bind matrices in ROW-MAJOR order, material float/RGBA properties, texture mappings and original PNG bytes. Unity's optimized one-influence encoding omits weights (implicit 1); one- and two-influence arrays are expanded with exact zero padding to vec4 for Three.js. Unity numeric IDs are strings to preserve values larger than JavaScript safe integers. URLs are rooted at /assets/mixer/.

Coordinates remain Unity's left-handed Y-up coordinates. Mirror the common assembly root in X for a Three.js scene. Attach each complete part prefab beneath the body node named Root_{rigType}_JNT. Use original inverse bind matrices and an identity bindMatrix with Three.js attached bind mode. Do not recalculate inverse binds: prefab rest transforms contain deliberate posture corrections. TextureLoader's ordinary flipY=true applies to the unmodified Unity UV data.

Animation tracks retain official hierarchy paths and are sampled at their official sample rate (30 Hz for these clips), using cubic Hermite values/tangents; quaternion samples are normalized. This is a sampling conversion of source animation, not authored procedural motion; interpolation between samples in Three.js can differ slightly from Unity's continuously evaluated curves. The 82 exported clips cover only shipped body animations; the optional separate weapon animation package is excluded.

Coverage and incomplete upstream references are enumerated in coverage.json and catalog.json. BuiltAssets cosmetic geometry/textures are included. AddonAssets runtime effects, effect prefabs, custom particle behavior and optional weapon animations are not exported. All 733 converted materials reference shader GUID 5c0053ca54ada496b95c440af4898a23; runtime must recreate that source shader's appearance and apply descriptor palette colors. Original .mat values are included. The export does not add support for part/gene combinations absent from the pinned upstream catalog.

Validation: all vertices/index and skeleton references checked during conversion; all 733 models CPU-skinned with original inverse binds, producing finite positions and weights summing to 1 within 0.001. Animation paths were checked against body prefabs: some upstream tracks target absent/reparented weapon/axe nodes; Some special attack/carry/hit clips also contain stale paths in Wetdog, Spiky and Frosty; Wetdog includes an obsolete Root_Character_Jnt/Hip_Bind hierarchy. These unresolved source tracks are listed in coverage.json and should be skipped; core Idle/Run/Walk body tracks resolve. Exact fixture #4200042 assembly is recorded in fixture-4200042-validation.json (3017 vertices; raw Unity bounds [-0.642451,0.001370,-0.796353] to [0.642451,1.432486,0.528435]).

Reproduction scripts are in the parent temporary asset directory: download-all.py, convert.py, validate-skin.py, validate-fixture.py and report.py. The unmodified sources remain under source/.
